# lithophane
[![Static Badge](https://img.shields.io/badge/Ada-2022-blue)](https://ada-lang.io/docs/arm)

Generate [lithophane](https://en.wikipedia.org/wiki/Lithophane) with Ada.

**Usage**
```
lithophane [options] <input_file>
```

**Options**
```
-h --help
-b --save-binary
-a --save-ascii
-p --save-pgm
-o<a_filename> or --output-name=<a_filename>
-H<a_height> or --height=<a_height>
-c<a_config_file> or --config=<a_config_file> ;
     note:  it overwrites previous options
```
